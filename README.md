Crafting polished React interfaces that feel fast, clear, and intentional — with a focus on performance, accessibility, and SEO.

- **5+ years** building modern web apps
- Frontend architecture, UI engineering, and Core Web Vitals
- Available for hire

## Stack

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) + [React Icons](https://react-icons.github.io/react-icons/)
- [Formspree](https://formspree.io/) (contact form)

## Features

- Dark / light theme with system preference
- Responsive layout (mobile-first)
- Lazy-loaded sections for a lighter first paint
- Optimized images (`srcset` / WebP) and LCP preload
- Semantic HTML, accessible controls, and strong contrast
- SEO: meta tags, Open Graph, `robots.txt`, sitemap

## Getting started

```bash
npm install
npm run dev
```

| Script            | Description                |
| ----------------- | -------------------------- |
| `npm run dev`     | Dev server with HMR        |
| `npm run build`   | Typecheck + production build |
| `npm run preview` | Preview the production build |
| `npm run lint`    | Run ESLint                 |
